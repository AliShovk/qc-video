# qc-video

Оркестратор вертикальных роликов: JSON-сценарий → озвучка → анимация → MP4 с проверкой качества.
Сделан для обзоров и гайдов [qantcore.space](https://qantcore.space), но не привязан к домену.

```bash
qc-video make specs/manus-hook.json
```

За 5–6 минут на 4 vCPU получается ролик 1080×1920 с хуком, цифрами, карточками и финальным адресом.

## Что внутри

| Шаг | Модуль | Что делает |
|---|---|---|
| 1 | `qcv/spec.py` | читает и валидирует JSON: первая сцена `hook`, последняя `final` |
| 2 | `qcv/voice.py` | Silero, профиль `eugene` / 0.94, тайминги реплик, SRT |
| 3 | `qcv/stage.py` | собирает HTML-сцену: неон, счётчики, прогресс-бар, луп |
| 3b | `qcv/board.py` | белая маркер-доска на rough.js: штрихи ложатся по ходу речи |
| 4 | `qcv/assemble.py` | кадры через headless Chrome (CDP) → H.264 |
| 5 | `qcv/audio.py` | синтезированная подложка, микс, −15 LUFS, фейд |
| 6 | `qcv/qa.py` | длительность, разрешение, громкость, клиппинг |
| 7 | `qcv/publish.py` | выкладывает mp4 и srt в веб-каталог |

## Голос

Профиль озвучки зашит в `qcv/voice.py`:

```python
VOICE_PROFILE = {
    'backend': 'silero',
    'speaker': 'eugene',
    'rate': 0.94,
    'lead': 0.3,
    'gap': 0.16,
}
```

Это тот же голос, которым собраны ролики Manus, LTX-2.5 и Cherry Studio.
Темп 0.94 и паузы 0.3/0.16 подобраны под 20–40-секундные вертикальные ролики.
Переопределяется в спецификации:

```json
"voice": {"speaker": "aidar", "rate": 0.9}
```

## Спецификация

```json
{
  "slug": "manus-hook",
  "title": "MANUS",
  "kicker": "обзор",
  "voice": {"speaker": "eugene", "rate": 0.94},
  "scenes": [
    {"type": "hook", "num": "4,8", "unit": "из 5 на Qantcore",
     "tag": "и это не реклама", "say": "…", "cap": "…"},

    {"type": "stats", "items": [
      {"value": "29", "label": "долларов за Pro"},
      {"value": "100", "label": "задач в день"}
    ], "say": "…"},

    {"type": "cards", "items": [
      {"title": "сам планирует", "text": "разбивает задачу на шаги"}
    ], "say": "…"},

    {"type": "board", "heading": "КАК ЭТО РАБОТАЕТ", "items": [
      {"title": "Tab", "text": "предсказывает правку целиком"},
      {"title": "Composer", "text": "меняет несколько файлов"}
    ], "say": "…"},

    {"type": "verdict", "score": "4.8", "note": "автономный агент", "say": "…"},

    {"type": "final", "headline": "ПОЛНЫЙ РАЗБОР", "sub": "Manus: тарифы",
     "address": "qantcore.space", "note": "обзоры и гайды", "say": "…"}
  ]
}
```

Правила:

- `title` показывается крупно в хуке и компактно на каждой сцене — имя инструмента видно всегда
- `say` — то, что произносит голос; длина реплики задаёт длительность сцены
- `cap` — короткая подпись внизу; если не задана, берётся начало `say`
- Цифры пишутся строками и анимируются счётчиком; `4.8` → «4,8»
- Первая сцена — всегда `hook`, последняя — всегда `final`

## Требования

- Python 3.11+
- FFmpeg
- Node.js (Chrome/Chromium для CDP-рендера)
- `torch` + `soundfile` для Silero
- Движки-зависимости по путям: `/opt/qantcore/htmlvid`, `/opt/qantcore/minibot`

Пути вынесены в `sys.path` в начале `assemble.py` и `voice.py` — при переносе в другое окружение поправьте их.

## Проверки качества

`qc-video` не отдаёт ролик молча: печатает отчёт.

```
{"duration": 20.65, "width": "1080", "height": "1920",
 "mean_db": -16.7, "peak_db": -1.2, "problems": [], "ok": true}
```

Падает с кодом 1, если:

- длительность ушла больше чем на 12% от ожидаемой
- разрешение не 1080×1920
- пик громкости выше −0.2 dB (клиппинг)
- средняя громкость вне коридора −22…−11 dB
- нет звуковой дорожки

Флаг `--force` публикует даже с предупреждениями.

## Ограничения v0.1

- Два визуальных слоя: тёмный неон (`hook`, `stats`, `cards`, `verdict`, `final`) и белая доска (`board`)
- Доска рисует маркером в темпе речи: каждая линия появляется, когда голос до неё доходит
- Сцены `mascot` (скелетная анимация) пока нет — движок готов, но не подключён
- Музыка синтезируется на лету, а не берётся из библиотеки
- Публикация настроена на каталог `/var/www/qantcore/video/reviews`
