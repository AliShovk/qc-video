Срез собран через YouTube Data API: 12 запросов по нашим темам (обзор нейросети,
локальная LLM, AI-агент, Qwen, DeepSeek, Cursor, RAG, Ollama и др.), 286 видео
с RU-локализацией, опубликованных после 01.06.2025.

Рабочая формула: **цифра + выгода + ограничение**. Например
«Qwen локально за 20 минут: 0 ₽ за токены, но нужно 8 ГБ».

## Что делаем иначе

1. **Длина 70–120 секунд.** Не 25. Восемь сцен вместо пяти.
2. **Три-четыре визуальные системы** чередуем между роликами, а не внутри:
   - `paper` — обзоры и разборы (кремовая бумага, скетч-робот);
   - `amber` — технические гайды (тёмный фон, тёплый акцент);
   - `teal` — продукты и сравнения;
   - `lime` — данные и цифры.
3. **Разные заходы:** цифра, противоречие, вопрос, «до/после».
4. **Заголовок с ограничением.** Не «обзор», а «что получится и чем заплатишь».
5. **Обложка:** лого + 3–5 слов + одна цифра. Без простыней текста.
6. **Первый кадр = обложка**, дальше сразу цифра или противоречие — не приветствие.

## Структура 90-секундного ролика

| Время | Сцена | Задача |
|---|---|---|
| 0–3 с | hook | цифра или противоречие, без вступления |
| 3–12 с | stats | 2–3 числа, которые подтверждают обещание |
| 12–25 с | diagram | как это устроено, 3 узла |
| 25–40 с | split | что нужно / сколько стоит |
| 40–55 с | code | одна команда, посимвольно |
| 55–70 с | film | три факта кадрами |
| 70–85 с | cards | ограничения и ошибки — доверие |
| 85–95 с | final | адрес и что делать дальше |

Ограничения показываем всегда: это то, что отличает разбор от рекламы.
